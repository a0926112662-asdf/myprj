使用 A4 裝訂版，設定 **A4、橫向、彩色、雙面短邊翻轉、實際大小 100%**。
此檔已排好裝訂頁序，不再選「小冊子」或「每張多頁」；列印後保持紙張順序，疊齊、對折，沿中央折線釘冊。
先試印第 1–2 面：正面為「內頁 15／封面」，背面為「內頁 1／內頁 14」，文字方向應一致。
交列印店時請說：A4 彩色雙面、短邊翻轉、100%，4 張紙對折騎馬釘成 A5。
