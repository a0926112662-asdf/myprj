## 印刷設定

請選 **A4 裝訂版**，設定 **A4、橫向、雙面、短邊翻轉、實際大小 100%**。
此檔已排好頁序，不要再選「小冊子」或「每張多頁」；使用彩色列印才能保留紅字提示。
建議先試印第 1–2 面（同一張紙的正反面）：正面應為 16／1，背面為 2／15，文字方向一致。
印好後按原頁序疊齊，對折，沿中央折線釘成冊。
若列印店代印，請提供 A4 裝訂版並告知：A4 彩色雙面、短邊翻轉、100%、四張紙對折騎馬釘成 A5。
