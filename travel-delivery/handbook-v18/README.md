# 東京自由行手冊 V18

[圖片預覽](preview/README.md)

K 字體：芫荽標題＋源泉圓體內文。24 頁；正文 1–18。每頁有水彩小插圖，裝飾頁各使用不同元素；手札與回憶頁為白底。

## 交給影印店

優先使用 [A5 出血版](tokyo-handbook-v18-a5-bleed.pdf)：A5 成品 148×210mm，四周出血 3mm，含裁切標示、TrimBox 與 BleedBox，請店家拼版、雙面彩色印製及騎馬釘。

若店家需要已拼版檔，使用 [A3 拼版](tokyo-handbook-v18-a3-printshop.pdf)：A3 橫向、雙面短邊翻轉、100% 實際大小。6 張 A3（12 面），沿外框裁切後對折裝訂；勿再次套用小冊子功能。

[A5 閱讀版](tokyo-handbook-v18-a5.pdf) 不含出血標示，供閱讀。[A4 裝訂版](tokyo-handbook-v18-a4-booklet.pdf) 適用雙面無邊界設備直接列印；一般設備仍可能有白邊。

保留全部裝飾頁，以維持行程與 QR 對頁。60 個 QR 在四種 PDF 均通過解碼檢查。
